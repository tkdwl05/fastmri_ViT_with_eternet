## 1. 결론

1. **사전 고정 1차 규칙: 50 epoch 후보 선정 없음.** 전제 조건 V3 가 충족되지 않았다. 로컬 4000 step 에서는 현재 방식(A)의 학습 손실 열세가 재현되지 않았다.
   - 측정값: 3001~4000 step 구간의 A / ref 손실 비 R_A = **−1.30 %** (t 95 % CI [−2.67 %, +0.07 %]). 기준은 ≥ +2 % 였다.
2. **같은 구간에서 pod 본 학습의 ETER-net 은 U-Net 단독보다 손실이 +10.4 % 높았다**(같은 배치 흐름, §3).
   - 로컬 U-Net 단독(ref)의 손실 수준은 pod U-Net 단독과 같다(0.0514 대 0.0518). 따라서 차이는 ETER-net 쪽 학습에서 생긴다.
   - 원인은 아직 확인하지 않았다.
3. 따라서 이 스모크는 원래 물으려던 질문, 곧 "각 조건이 교란을 없애는가"를 시험하지 못했다. 아래 조건별 결과(포화·슬라이스 정보·SSIM)는 기술 자료로만 읽는다.
4. 초기값만 다른 U-Net 단독 두 회차(ref·ref2)의 SSIM 차가 **+0.0081** 이다(step 4000, 256 슬라이스).
   - 이 차이는 깨지지 않은 조건들(A·B·D·E·EC) 사이의 SSIM 차보다 크다.
   - 따라서 4000 step SSIM 으로는 조건 간 우열을 말할 수 없다.
5. 확실한 관측은 두 가지다.
   - **C(GRU 워밍업)는 워밍업이 끝나는 순간 발산했다.** 게이트를 더한 EC 는 같은 시점을 넘겼다.
   - **B(GRU LR ×0.1)만 GRU 포화를 없앴다.** 다만 손실·SSIM 이득은 없었다.
6. 해석 범위: 단일 시드, 4000 step(0.49 epoch), cosine 감쇠 전 LR 에서의 선별 시험이다.
   - 주장할 수 있는 범위는 "이 설계·공유 레시피에서, 시험한 조정으로는 이득이 확인되지 않음"까지다.
   - "시퀀스 모듈 불필요·해롭다"로 일반화하지 않는다.

2. **데이터 차이**
   - train 목록이 다르다(pod 65,060 슬라이스, 로컬 65,028).

   - cuDNN RNN 알고리즘이나 fp16 연산 순서 차이는 남는다.

## 4. 조건별 관찰

- **A (현재 방식)**
  - 포화 과도기(최대 +90 %, 그림 `fig_loss_ratio.png`)를 지난 뒤에는 ref 와 같거나 조금 낮은 손실로 진행했다.
  - sat_v 는 0.50 부근에서 유지됐다.
  - 시퀀스 출력 치환 시험(E256)에서 출력을 0 으로 바꾸면 SSIM 이 0.054 떨어지고, 다른 볼륨의 출력으로 바꾸면 0.014 떨어진다.
  - 인접 슬라이스 치환은 다음 슬라이스로 바꾸면 0.008 떨어지지만, 이전 슬라이스로 바꾸면 떨어지지 않는다(−0.0002). 방향이 비대칭이라 슬라이스 고유 정보를 쓴다는 근거로 읽지 않는다.
  - 출력 에너지 중 볼륨 공통 패턴 비율(common_frac)은 0.97 이다. 10-12 진단과 같은 그림이다(`ss2d_unused_diag` 메모).
- **B (GRU LR ×0.1)**
  - GRU 포화가 없는 유일한 조건이다(sat_v 0.000).
  - 그러나 3001–4000 구간 손실이 +1.04 % 높고, SSIM 은 ref 대비 −0.0050 이다. 이 SSIM 차는 ref2 잡음 폭 안이다.
  - 슬라이스 정보 사용 증거도 없다.
  - 10-14 감사의 o-ETER 시험("GRU LR×0.1 은 포화를 없애도 품질 동일")과 같은 방향이다.
- **C (GRU warmup 1000)**
  - 워밍업이 끝나 GRU LR 이 2e-4 에 닿은 직후 발산했다. step 1050 에 시퀀스 출력 RMS 가 0.05 에서 0.57 로 튀었다.
  - step 1150 부터는 기울기가 계속 NaN 이었고, GradScaler 가 하한 1024 에 고정됐다. 이후 2885 step 이 모두 건너뛰어졌다.
  - 끝까지 회복하지 못했다(SSIM 0.364).
  - 이 결과는 게이트 없이 warmup 뒤의 full LR 로 가면 위험하다는 것이다.
- **D (출력 크기 맞춤)**
  - 포화가 가장 깊었다(sat_v 0.89). 손실 +6.3 %, SSIM −0.011 로 모든 지표에서 가장 나빴다.
  - 설계 단계 측정의 예상과 같다. D 는 U-Net 이 시퀀스 채널을 읽는 가중치를 0.06 배로 줄인 것과 같고, Adam 은 기울기 크기에 불변이라 포화가 줄지 않는다.
- **E (zero-init 게이트)**
  - SSIM 은 ref 와 같다(+0.0004, p 0.42). 손실은 +1.27 % (CI 가 0 을 포함)다.
  - 포화는 30~40 step 에 그대로 생겼다(sat_v 0.75). 설계 실측에서 예상한 대로, Adam 이 게이트 크기를 상쇄하기 때문이다.
  - S2 1차 통과(+0.00018)는 크기가 사실상 0 이다. 대칭 치환에서는 통과하지 못한다.
- **EC (게이트 + warmup)**
  - C 와 달리 warmup 끝(step 1050, 손실 0.17 로 일시 상승)을 넘겼다. 이후 NaN 은 0 회, AMP 하한 도달도 0 회였다.
  - 포화 0.78, 손실 +1.76 %, SSIM −0.0021 로 이득이 없다.

## 5. 잡음 기준 — SSIM 해석 주의

- ref2 와 ref 는 U-Net 초기값만 다르다. 그런데도 step 4000 SSIM 차가 +0.0081 ± 0.0006 이고, 슬라이스 단위 부호 검정은 p = 1.5e-27 이다.
- 따라서 **슬라이스를 독립 표본으로 본 p 값은 회차 간 변동을 반영하지 못한다.**
  - 예: A − ref 의 +0.0022(p 7.6e-5)는 이 변동보다 작아서 "A 가 낫다"는 근거가 아니다.
  - 마찬가지로 B·EC 의 음의 차이도 "나쁘다"는 근거가 아니다.
- 손실 비(R)는 같은 배치 짝 비교라 회차 간 변동이 작다. ref2 의 3001–4000 구간 손실 비는 +0.29 %, SE 0.77 % 였다.
- 이 점은 50 epoch 비교의 해석에도 적용된다. 단일 회차끼리의 슬라이스 짝 검정 p 값만으로 모델 차이를 주장하지 않는다.

## 6. 부수 확인

- v8fix 의 분리형 weight decay 3e-5 는 이 LR 범위에서 수치상 작동하지 않는다.
  - 한 step 의 상대 감쇠 lr·wd ≤ 6e-9 가 fp32 반 ulp 보다 작아서 가중치가 그대로 반올림된다. pod 런도 같다.
  - 실험에서도 확인했다: 0 입력 슬라이스의 갱신량이 정확히 0.0 이었다.
  - 방법 절의 "WD 3e-5" 서술은 "실효 0"으로 정정해야 한다.
