### 08-20 — 기준선(VarNet) 공식 규약 대조 · zero-coil NaN 버그 수정 · 층화 표본 예비 실행

- **공식 대조**: fastMRI `fastmri_examples/varnet/`(README + `run_pretrained_varnet_inference.py`)와
  우리 `eval_paired_baselines.py` 를 대조. 일치 확인 = 모델 생성자(12 cascade/chans 18/sens 8·4),
  FFT 규약(ifftshift→ortho→fftshift), 마스크 축·ACS pad 공식, 마스크 밀도(우리 119/384 ≈ 공식
  `EquiSpacedMaskFunc` 120/384. 참고: `EquispacedMaskFractionFunc` 는 95). 공식은 `num_low_frequencies`
  를 넘기지 않고 마스크에서 자동 검출 — 우리의 명시값 31 과 동일 결과.
- **🔴 버그 수정**: 데이터로더가 코일을 16채널로 zero-pad 하는데, VarNet `SensitivityModel` 은 코일마다
  `NormUnet` 을 개별 적용 → all-zero 채널에서 std=0 → NaN 이 `divide_root_sum_of_squares` 로 전 코일
  전파. 검증셋 코일 분포상 **464 파일 중 197개(슬라이스 3,122/7,334 = 42.6%)** 가 16코일 미만이라
  풀런했으면 그만큼이 통째로 무효였다. 실측 코일만 전달하도록 수정(4코일 볼륨: 수정 전 NaN 100% →
  수정 후 정상, ssim 0.9734). 기존의 "ortho ~1e-4 스케일이 sens 추정을 발산시킨다"는 진단은 **오진**
  으로 확인 — VarNet 은 positively homogeneous(`VarNet(a·k)=a·VarNet(k)`)라 스케일은 지표에 무영향.
- **🔴 캐비엇 추가**: 공식 README 원문 *"The leaderboard model was trained where the `train` split
  included both the `train` and `val` splits from the public data"* — U-Net·VarNet leaderboard 가중치
  **둘 다 train+val 합본 학습**. 즉 **본 검증셋 전체가 두 기준선의 학습 데이터**이므로 기준선 수치는
