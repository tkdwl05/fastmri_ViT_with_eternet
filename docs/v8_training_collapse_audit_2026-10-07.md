# v8·v9 학습 붕괴 감사 (2026-10-07)

> **요지**: v8 의 모든 런(주 실험·E1·1b·U-Net 단독·pixel-GRU)과 v9 에서 시퀀스 모듈 가중치와 U-Net 파라미터의 약 97% 가 늦어도 epoch 5 에 |w|≈2e-40(fp32 비정규 수 바닥)으로 붕괴했다. 원인 = Adam 결합형 L2 weight_decay 3e-5(교수님 원본 1e-7, v5 에서 도입) + 전역 clip_grad_norm 1.0(×1e6 강도 단위 L1 때문에 grad norm 44~76 → clip 계수 0.01~0.02). 따라서 GRU·SS2D·U-Net 단독 비교 수치는 시퀀스 모듈 효과가 아니다.
> 메인 세션 직접 확인(10-07): 2회차 GRU 637.1M 100% |w|<1e-30(max 2.1e-40), SS2D 모듈 99.5%, U-Net 96.9~97.4%, down_path.4·up_path.0 100%.
> 원자료·스크립트: results/audit_2026-10-07/ (git 무시). 아래는 감사 워크플로(조사 5 + 반박 검증 + 종합) 종합 원문.

## 학습 방법 감사 결과: 시퀀스 모듈은 학습 초기에 소멸했습니다

### (1) 답: 학습 방법이 잘못된 것은 아닌가?

네, 학습 방법에 결함이 있습니다. 결함은 모델 코드나 데이터 코드가 아니라 **최적화 설정**에 있습니다.

- **소멸한 것.** v8의 모든 GRU·SS2D 런은 늦어도 epoch 5(가장 이른 체크포인트)에 시퀀스 모듈의 입력 경로가 fp32 비정규 수 바닥값(|w|≈2.1e-40)까지 떨어져 있었습니다. 공유 U-Net도 파라미터의 약 97%가 같은 상태입니다.
  - 기준 모델(ETER-net, GRU)은 기능상 U-Net 단독 구조와 같습니다.
  - SS2D는 "U-Net + 입력과 무관한 상수 20채널"입니다.
- **결함(실험을 무효화함).** `torch.optim.Adam(model.parameters(), weight_decay=3e-5)`가 모든 파라미터에 결합형 L2를 겁니다(`main_train_pure_v8.py:225-226`, config `:37`). 교수님 원본은 1e-7이고(`configs/myConfig_choh_ViT_ETER_R4regular.py:42`), 3e-5는 v5에서 들어왔습니다.
  - 6-step 재생 실험에서 wd=0이나 AdamW로 바꾸면 수축이 사라졌습니다. 즉 이 설정이 소멸의 **필요조건**입니다.
- **필요조건은 아니지만 소멸을 키운 설정과 설계 요인.** 아래는 소멸의 필요조건이 아니라 결과를 키운 요인입니다.
  - 전역 `clip_grad_norm_(1.0)`(`:384`).
  - ortho iFFT와 ×1e6/1e4/1e6 배율(`dataloader_h5_v5.py:32,131-133`). 이 때문에 초기 grad norm이 48~98이고 그 98% 이상이 `unet.last`에서 나오며, clip 계수가 약 0.01~0.02가 됩니다.
  - 정규화 없는 depth-5 U-Net의 깊은 층 기울기 소실.
  - zero-filled 영상 우회 경로(교수님 d-ETER 설계). 이 경로 때문에 모듈이 죽어도 성능이 떨어지지 않아 소멸이 드러나지 않았습니다.
- **정상인 것.** 다음은 문제가 없습니다.
  - 데이터 파이프라인: 입력·GT 대응, flip, 마스크, k-space 중심.
  - GRU 구조: 교수님 `ETER_hybrid_GRU_DFU`와 출력 max|diff| = 0.0.
  - 입력 포화 없음, AMP NaN-skip 0건.

"덜 학습되었다(under-training)"는 해당하지 않습니다. 모듈은 흡수 상태(Adam exp_avg = 0)에 있어서 학습을 더 돌려도 살아나지 않습니다.

### (3) 반박되거나 정정된 항목

- **clip 1.0이 필요조건이다**: 반박. clip이 없어도 깊은 층은 같게 수축합니다. clip은 증폭 요인입니다.
- **교수님 스케일은 1e5/1e3/1e5다**: 반박. 실제로 쓰인 로더 `_v4_1`(240817)은 1e6/1e4/1e6입니다. 차이는 FFT 정규화에서 오고, 영상·label이 384~551배 커집니다(.mat 1개 실측 ≈551 = √(768·396)).
- **wd를 1e-7로 되돌리면 해결된다**: 반박. 결합형이면 1e-7도 기울기 0인 가중치를 3.2만~6.5만 step 안에 소멸시킵니다. 수축이 없던 것은 AdamW와 wd=0뿐입니다.
- **v9처럼 A_log·D만 no-WD로 빼면 된다**: 반박. v9는 A_log·D를 보존했지만 입력 경로는 ep5에 소멸했습니다.
- **SS2D LayerNorm의 진폭 소거가 결과를 설명한다**: 현재 결과에는 영향 0입니다. 입력 경로가 이미 0입니다.
- **GRU 출력이 작아서(0.035) 무시됐다**: 반박. 학습 후 GRU 출력은 약 1.7e-40으로, 작은 것이 아니라 0입니다.
- **epoch이 부족했다**: 반박. ep5에 이미 소멸했고, ep50 정체는 cosine LR이 1e-6까지 내려간 탓입니다.
- **fp16이 원인이다**: 필요조건이 아닙니다. fp32 재현에서도 수축합니다.
- **U-Net 시퀀스 slice가 먼저 죽고 GRU가 따라 죽었다**: 근거가 없습니다. 모의에서는 GRU가 먼저입니다(중앙값 122 vs 419/739 step).
- **SS2D slice가 산 이유는 출력 스케일이 커서다**: 반박. 상수 bias 성분 때문입니다.
- **코일 불일치가 기여를 억눌렀다**: 평가 층화로 반박. 교수님 데이터와 비슷한 49개 볼륨에서 기여가 가장 작습니다(GRU +0.0003, SS2D +0.0000).
- **교수님 논문도 R4 이득이 +0.002다**: 같은 절제가 아닙니다. J. Imaging Model 3에는 U-Net이 없고, nMSE 이득은 −23%로 우리(−1~2%)와 다릅니다.
- **출력 0 대체가 올바른 시험이다**: 아닙니다. 상수 bias 제거 효과를 재게 됩니다. 다른 샘플의 출력으로 바꾸는(shuffle) 시험이 맞고, 결과는 비트 단위로 같습니다.
- **SSIM 기울기 몫은 약 1%, 항상 L=255다**: 정정. 몫은 1~4%이고 초기에는 L=2입니다.
- **GRU 모델 = U-Net 단독과 같은 함수다**: 정정. 같은 구조이지 같은 가중치가 아닙니다.

### (4) R=4에서 U-Net 단독 ≈ ETER-net을 어떻게 해석할 것인가

세 해석 중 어느 것도 정확히 맞지 않습니다.

- **기준 모델(GRU)은 경로가 끊겨 무시된 상태입니다.** "중복이라 안 쓰였다(used-but-redundant)"도, "덜 학습됐다(under-trained)"도 아닙니다. 시퀀스 출력과 그 출력을 받는 가중치가 모두 0입니다.
- **SS2D는 입력과 무관한 bias로만 쓰였습니다.** 21개 슬라이스(run2)에서:
  - U-Net 단독 0.91386
  - GRU는 정상 = 0 대체 = shuffle = 0.91421
  - SS2D는 정상 = shuffle = 0.91452, 0 대체 시 0.91389
- 따라서 "U-Net 단독 ≈ ETER-net"은 **경험적 발견이 아니라 구조상 성립하는 항등식**입니다. 이 데이터로는 R=4에서 시퀀스 모듈이 기여하는지 여부를 어느 쪽으로도 말할 수 없습니다.
- **모델 간 차이 0.9127~0.9141은 U-Net 생존 파라미터 수와 함께 움직입니다.** Pearson r = 0.994(50ep, n=5), 0.875(E1, n=6, Spearman p = 0.11)입니다. 상관일 뿐이라 인과로 단정하지 않습니다.
- **p<0.001은 모델 효과의 증거가 아닙니다.** 2회차 ETER-net과 U-Net 단독의 Δ +0.0010(p≈2e-51)은 같은 구조를 두 번 학습한 결과 사이의 차이입니다. 볼륨 대응 검정은 학습 회차 간 변동을 반영하지 않습니다.
- **소멸과 별개로 성립하는 사실.** `data_img = 100·ifft2c(data)`는 정확한 가역 선형 관계입니다(상대오차 ≤9.7e-8). k-space 입력에는 zero-filled 영상에 없는 정보가 없습니다. 모듈이 살아 있어도 더할 수 있는 것은 전역 수용영역이나 학습된 변환뿐입니다.

  - 5 epoch 점검에서 SS2D 가 "사용 안 됨"이고 U-Net 단독과의 차이가 시드 변동 범위 안이면, SS2D 50 epoch 는 큐 뒤로 미룹니다(사용자 결정).
  - 후속 시험 후보는 순서대로 다음과 같습니다(모두 사용자 결정 후).
    1. CPU 2D 도메인 변환 용량 시험(GPU 0)
    2. SS2D 앞단에 코일별 2D IFFT 를 붙인 영상 도메인 변형 — 원 SS2D 를 대체하지 않는 별도 변형
    3. `norm_in` 제거
    4. 스캔 경로를 켜는 초기화
