## 보류 — 현행 유지 (2026-10-01 사용자 결정)

교수님이 직접 쓰거나 고친 표현과 겹치는 아래 9건은 바꾸지 않습니다. 교수님 확인 없이 원고·문서 어디에서도 일괄 변경하지 않습니다.

1. ETER-Net 표기와 'ETER' 단독 표기
2. SS2D 약어 풀이와 Mamba·SSM 관련 서술
3. brain mask 명칭(형용사형 brain-masked 포함)
4. 원고에서 교체 부분을 부르는 교수님 문구(도메인 변환 모듈, 순차적 입력을 처리하는 모듈)
5. multicoil / multi-coil 표기
6. U-Net 부분 명칭(dual-frame skip, DFU, 후처리 U-Net)
7. 교수님이 직접 넣은 문구(significantly smaller, 파라미터로 depth=5, flattened 2D 고차원 입력, 파라미터의 수, skip 계수 등)
8. ringing / 링잉 아티팩트
9. bi-GRU 입력을 '384개 행의 시퀀스'로 설명한 서술과 그림 2(a)의 입력 라벨

## D. 사실 오류 정정 (문서)

| 틀린 서술 | 바른 서술 |
|---|---|
| Adam의 weight_decay는 L2 정규화와 약간 다르다 | `torch.optim.Adam`의 weight_decay는 그래디언트에 λθ를 더하는 결합형 L2 정규화이고, 감쇠를 분리하는 AdamW와 다르다 |
| SSIM의 C1·C2는 regularizer | C1·C2는 분모가 0에 가까워지는 것을 막는 안정화 상수 |
| SSIM은 local mean/variance 기반 | SSIM은 국소 평균·분산·공분산으로 휘도·대비·구조 세 항을 비교 |
| 채널 불변 잔차 블록 | 채널 수를 유지하는 잔차 블록 |
| DC 블록으로 '증강' | DC 블록 추가(구조 확장) |
| 비트반전 순서 부분집합을 '층화 표본'으로 부름 | 전 볼륨에 고르게 분산된 부분 집합(계통 추출) |
| GRU 순환 비용을 O(L²)로 서술 | 순환 비용은 시퀀스 길이에 선형, 파라미터 수가 hidden 크기 N에 대해 O(N²) |
