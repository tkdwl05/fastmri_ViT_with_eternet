| 모델 | best epoch | SSIM | PSNR (dB) | NMSE | L1 (×10⁻⁶) | params |
|---|---:|---:|---:|---:|---:|---:|
| GRU (기존) | 50/50 | 0.9126 | 33.78 | 0.00449 | 9.002 | 668M |
| SS2D 통제판 (v8) | 48/50 | 0.9140 | 33.90 | **0.00438** | 8.883 | 31M |
| 강화 SS2D (v9 unleashed) | 78/80 | **0.9145** | **33.92** | 0.00439 | **8.879** | ~33M |

### 1.3 학습시간 — 정본과 폐기값 (⚠ 가장 자주 틀리는 항목)

**정본은 `draft_ko_v2.md` Table 5.** 산식 = 5-epoch 체크포인트 저장 간격의 **중앙값**(검증 포함
wall-clock, 재시작·정전 outlier 구간 제외).

| 모델 | h/ep (정본) | 총 epoch | 1회 학습 소요 |
|---|---:|---:|---|
| GRU | 2.41 | 50 | 약 120 h ≈ **5.0일** |
| SS2D 통제판 | 3.07 | 50 | 약 154 h ≈ **6.4일** |
| 강화 SS2D (unleashed) | 2.84 | 80 | 약 227 h ≈ **9.5일** (실측 완주 9.4일과 일치) |
| radapt | ✎미측정 | 80 | ✎ (docs 의 2.61 h/ep 는 폐기 기준) |

- 실측 end-to-end 완주 1건: unleashed **2026-07-21 13:02 UTC → 07-30 22:51 = 9.4일**.
  80 × 2.84 = 227 h = 9.46일 이므로 정본 h/ep 와 정합한다.
- best 도달 wall-clock: **강화판 ≈187 h (ep66×2.84) > 통제판 ≈147 h (ep48×3.07)**.

**폐기값 — 인용 금지:**

| 폐기값 | 출처 | 폐기 사유 |
|---|---|---|
| 2.78 h/ep (v8 SS2D), 2.51 h/ep (v9) | `docs/v9_mamba_unleashed_and_radapt.md` | 측정 기준 불일치 (부록 D 항목 6) |
| best 도달 181 h vs 133 h | 〃 §11 | 위 폐기 h/ep 기반 → 정본은 187 h vs 147 h |
| 2.61 h/ep (radapt) | 〃 §10 스모크 | 위와 동일 기준 |
| "학습 1회 9일에서 12일" | 중간보고서 3장 | 9일은 unleashed 실측과 부합하나 **12일의 근거 없음** ✎ |

주의: v8 두 arm(GRU 2.41 / SS2D 3.07)은 동일 실행환경이라 상호 비교 가능하다. **epoch 당
학습시간은 GRU 가 더 빠르다.** 강화판(2.84)은 v8 완주 후 컨테이너·데이터로더 환경 개선을 거쳐
학습되어 v8 과의 wall-clock 직접 비교에 환경 confound 가 있다(Table 5 각주 ‡).
**따라서 논문의 효율 주장은 "학습 속도"가 아니라 "파라미터 21× 감소 + 동등 이상 품질"에 둔다.**

## 2. 서술 원칙

### 2.1 금지 서술

| 금지 | 대체 |
|---|---|
| composite 지표(SSIM·PSNR·NMSE 가중합) 인용 | **표준 지표만** — SSIM 주지표 + PSNR/NMSE/L1 병기 (2026-08-07 결정) |
| 강화판이 "같은 학습량에서 더 좋다" | "더 긴 스케줄(80ep)을 소화해 최종 품질을 근소하게 상회하였다" |
| 강화판 이득을 단정적으로 서술 | "이득의 크기는 작고 지표·서브그룹에 따라 균일하지 않다" |
| 기준선(U-Net/E2E-VarNet)과의 우열 판정 | "참고선" — 리더보드 가중치는 train+val 합쳐 학습 → 본 검증셋 전체가 누수 |
| "SS2D 가 DC 덕분에 이겼다"는 해석을 남겨 둠 | DC 완전 배제 조건에서 격차 확대 → 해당 해석은 성립하지 않음 |

### 2.2 반드시 유지할 caveat

- **단일 시드**. Fig. 2 는 단일 시드의 단일 궤적임을 캡션에 명시.
- **강화판 matched-ep50 은 0.9130 으로 통제판 best(0.9140)에 미달.** ep64 동률, ep66 상회.
- **NMSE 는 평균 기준 통제판이 근소 우세**(Δ −1.0×10⁻⁵). 순위 기반으로만 4지표 전부 강화판 우위.
- **평균 차이 95% CI 가 0 을 배제하는 것은 SSIM 뿐**. PSNR·L1 은 CI 가 0 포함.
- **contrast 서브그룹 불균일**: SSIM 우위 비율 AXFLAIR 67.8% ~ AXT1 48.2%(역전).
- **데이터는 fastMRI 뇌 단일 부위**, 사후 마스킹 언더샘플링(실제 가속 촬영 아님), 판독의 정성평가 없음.
- **GRU ringing 은 뇌 마스크 바깥**이라 정량 지표에 반영되지 않는 차이임을 명시.
- 컨트라스트는 AXFLAIR 단일이 아니라 **AXT1/AXT1POST/AXT1PRE/AXT2/AXFLAIR 혼합**.

### 2.3 연구 서사 (초안 §1·§5 및 보고서 공통)

교란변수 제거 과정이 이 연구의 방법론적 기여다. 요약하면:

1. v7_titan 무승부(0.9084 vs 0.9083)는 해석 불가 — 시퀀스 모델·배치 크기·최종 합성 구조 3개가 동시 변동.
2. 원 ETER-Net 논문·코드에 **DC 블록 없음** → DC 는 v4 에서 SS2D 쪽에만 임의 추가된 confound.
3. ViT·DC 배제한 순수 골격에서 단일 변수 통제 → SS2D 우위(§1.2).
4. 평가 지표 오류 2건(자체 SSIM 동적범위 버그, 배경 부풀림)이 선행 — **모델 수정에 앞서 지표를 검증**.

## 3. 한국어 문체 표준

지도교수 연구계획서 문체를 기준으로 한다(2026-08-21 사용자 제공 예시).

### 3.1 문체

- 서면 격식체: `~하였다 / ~되었다 / ~하고자 한다 / ~할 수 있다`. 구어체 `~했다 / ~됐다` 금지.
- 1인칭·조직 지칭 금지: "우리", "교수님" → **"본 연구", "본 연구실", "제안 모델", "지도교수"**.
- 서사형 소제목 금지("만들고, 실패하고, 원인을 찾다") → 내용 서술형("기본 구조 구현").

### 3.2 주관적 어휘 금지 (2026-08-21 사용자 지시)

`확인했다 / 확정했다 / 발견했다 / 결정했다 / 믿었다 / 명확했다 / 반박됐다 / 실증했다`
→ `나타났다 / 드러났다 / 산출되었다 / 도출되었다 / ~로 파악된다 / ~자로 제외하였다 / ~은 성립하지 않는다`

극적·수사적 표현도 삭제한다(예: "모델이 아니라 자(尺)가 잘못돼 있었다", "결론은 명확했다",
"정직한 단서를 붙여야 한다").

em dash(—)·en dash(–)·굽은따옴표 사용 금지. 3항 나열 강박, `-ing`형 수식 남발, 홍보성 형용사,
일반화된 마무리 문단("~할 것으로 기대된다" 류의 근거 없는 총평) 금지.

### 5.3 지시 3 — 문체 예시 제시

지도교수 연구계획서(가. 연구목적 및 필요성 / 나. 연구내용 및 방법 / 다. 연구의 기대효과 및
활용방안) 발췌를 문체 기준으로 제시. 특징:

- 목적문을 "~하는 것이다"로 단언, 필요성은 배경→한계→본 연구 순으로 전개
- 용어를 국문 정식명칭 + 영문 병기(`가속화정도(acceleration factor)`, `underdetermined problem`)
- 선행연구 한계를 명시하고 그 극복을 목적으로 연결하는 구조
- **핵심 목적을 "가속화정도마다 다른 모델을 학습해야 하는 한계 극복 → 단일 모델"로 서술**

→ §3.1·§3.3 으로 규칙화. 중간보고서 1장 가항을
`(1) 연구의 목적 / (2) 연구의 필요성 / (3) 선행 연구와 본 연구의 위치` 로 재편하고,
목적문 첫 문단에 단일 모델 목표를 명시.
