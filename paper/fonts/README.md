# paper/fonts

Liberation Sans 2.1.5 (Regular / Bold / Italic / BoldItalic) — SIL Open Font License 1.1
(`LICENSE_LiberationFonts.txt`). Arial 과 metric-compatible 한 sans 로, 논문 그림 텍스트용
(`paper/make_figs_conf_arch.py` 가 `matplotlib.font_manager.addfont` 로 등록; 없으면 DejaVu Sans 로 폴백).
출처: https://github.com/liberationfonts/liberation-fonts (release 2.1.5, 2026-09-08 다운로드).
